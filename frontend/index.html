Calibration

Trim each servo so the 3D model matches the real robot: servo = direction × angle + offset.

While Setup is open, the selected leg is held with every joint at its neutral angle, so the servo sits exactly at the Offset. Drag Offset across the full 0–180° to sweep the servo and stop where the limb is neutral (femur: thigh horizontal).

Test direction moves the selected joint 30° and back. The real joint must move the same way as the 3D model; if it moves the opposite way, click Flip direction (the offset re-centres so the joint keeps its full range) and test again.

Servo min and max decide each motor’s range: changing either one re-centres the offset so the joint’s whole movement fits between them. Narrow them if a limb hits a mechanical stop. Offset is only a fine trim afterwards.
